# Source and asset provenance

DiskSense is an original Swift implementation. Earlier exploration of AppCleaner and Disk Space Analyzer informed the desired product behavior. This source distribution contains no bundled reference-app executables, decompiler dumps, extracted icons, or copied artwork.

The app icon is generated from the repository's AppKit drawing script; Orbit is drawn with SwiftUI shapes. System symbols are supplied by macOS. Runtime dependencies are Apple-provided SwiftUI, AppKit, Foundation, CryptoKit, Darwin, and SQLite3. There are no downloaded third-party source packages.
