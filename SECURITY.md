# Reporting security issues

Do not post private file paths or scan databases in public issues. For a cleanup safety or privacy vulnerability, use GitHub's private vulnerability reporting when available, or contact the repository owner privately before posting details.

LintGoblin removes only explicitly reviewed paths. Trash is the default; a separate permanent deletion mode requires typed confirmation and has no restore. It never empties Trash automatically. It does not require network access or collect telemetry. Protection checks reduce risk; users should still review every selected path and maintain backups.
